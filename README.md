# Devichand Budagam

Personal website at [devichand.com](https://devichand.com). Built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme. Push to `main` to deploy.

## Where to edit

| What | File |
|---|---|
| About | `_pages/about.md` |
| News | `_news/` |
| Blog posts | `_posts/YYYY-MM-DD-title.md` |
| Publications | `_bibliography/papers.bib` |
| Repositories | `_data/repositories.yml` |
| Services | `_pages/services.md` |
| CV | `_pages/cv.md` |
| Social links | `_data/socials.yml` |
| Site settings | `_config.yml` |
